# 1 背景

为统计关注的道路的路口、路段、区域的车辆数据，编写此文档说明。

# 2 名词解释

| 编号 | 名词缩写 | 名词解释                               |
| ---- | -------- | -------------------------------------- |
| 1    | 路网     | 根据实际需要，绘制的重点关注的道路信息 |
| 2    | 路口     | 路网中的关注的路口                     |
| 3    | 路段     | 路网中的关注的路段                     |
| 4    | 区域     | 路网中的区域                           |

# 3 需求

## 3.1 车流量数

按小时粒度统计经过路口、路段的某种类型某颜色的车辆数。例如：

| 字段         | 类型   | 说明                                                         | 样例        |
| ------------ | ------ | ------------------------------------------------------------ | ----------- |
| dataTime     | 字符串 | 小时粒度（YYYYMMDDHH）                                       | 2025112801  |
| roadNetCode  | 字符串 | 从路网获取，路口或路段的编号                                 | 11224100750 |
| roadNetType  | 整型   | 路口：1，路段：2                                             | 1           |
| vehicleType  | 整型   | 车辆类型 1：两客一危，2：货车                                | 1           |
| vehicleColor | 整型   | 车牌颜色 1: 蓝色，2: 黄色，3: 黑色，4: 白色，5: 绿色，9: 其他，91: 农黄色，92: 农绿色，93: 黄绿色，94: 渐变绿 | 2           |
| vehicleCount | 整型   | 车流量数                                                     | 具体的数值  |

## 3.2 消息样例

```json
{
    "dataTime": "2025112801",
    "roadNetCode": "11224100750",
    "roadNetType": 1,
    "vehicleType": "10",
    "vehicleColor": 2,
    "vehicleCount": 6
}
```

# 4 数据说明

1. 数据以消息形式推送到 Kafka 集群。
2. 每天的数据最好能在第二天凌晨 3 点前生成完成，并推送到 Kafka。
3. 如果同一辆车，在一个小时内三次经过一条路段，算 3 辆车。
