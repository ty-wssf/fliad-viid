## 1. 两客一危车辆 GPS 数据查询接口

### 接口信息

- 接口地址：`http://{ip}:{port}/jkfw/region/getyzlkywgps`
- 请求方式：GET
- 数据范围：仅包含湘牌车在全国的 GPS 数据

### 请求参数

#### Header 参数

| 参数字段名   | 字段示意 | 是否必填 | 备注                                         |
| ------------ | -------- | -------- | -------------------------------------------- |
| token        | 密钥     | 是       | 固定值：8914dfc5-beca-45c9-918c-01791b9c8b62 |
| Content-Type | 数据格式 | 是       | 固定值：application/json                     |

#### Query 参数

| 参数字段名 | 字段示意     | 是否必填 | 备注                                                         |
| ---------- | ------------ | -------- | ------------------------------------------------------------ |
| kssj       | GPS 开始时间 | 是       | 格式：yyyy-mm-dd hh24:mi:ss，不能跨年查询                    |
| jssj       | GPS 结束时间 | 是       | 格式：yyyy-mm-dd hh24:mi:ss                                  |
| size       | 返回条数     | 否       | 最大值 10000 条，默认 10000 条；仅统计数量时建议设为 1 条（性能最优） |

### 返回数据格式

```json
{
  "msg": "返回描述",
  "code": "返回代码",
  "data": "数据内容json字符串",
  "success": "是否成功标志位"
}
```

### Data 字段详情

| 字段名       | 字段描述     | 备注                             |
| ------------ | ------------ | -------------------------------- |
| total        | 统计总数     | 符合查询条件的总记录数           |
| id           | 流水编号     | 唯一标识每条 GPS 记录            |
| vehicleNo    | 号牌号码     | 车辆车牌号（湘牌）               |
| vehicleColor | 号牌颜色     | 代码值，对应【GPS 号牌颜色】字典 |
| gps_time     | GPS 过车时间 | 格式：yyyy-mm-dd hh24:mi:ss      |
| lon          | 经度         | 地理坐标经度值                   |
| lat          | 纬度         | 地理坐标纬度值                   |
| vec1         | 车辆速度     | 单位：Km/h                       |
| direction    | 方向         | 正北为 0 度，顺时针偏转度数      |

## 接口调用说明

1. 时间范围限制：`kssj`与`jssj`不能跨年度，否则查询失败
2. 性能优化：仅需统计记录总数时，建议将`size`参数设为 1，可显著提升响应速度
3. 数据格式：返回的`data`字段为 JSON 字符串，需二次解析获取具体 GPS 数据
4. 号牌颜色：需通过【GPS 号牌颜色字典】解析`vehicleColor`字段的代码值
