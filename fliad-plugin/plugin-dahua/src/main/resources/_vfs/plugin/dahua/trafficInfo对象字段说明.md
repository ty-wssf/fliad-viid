# trafficInfo 对象字段说明

## 1. m_PlateNumber
- **含义**: 车牌号码
- **类型**: 字符串

## 2. nNumOfCycling
- **含义**: 骑车人数
- **类型**: 整数

## 3. emCap
- **含义**: 骑手帽类型列表
- **类型**: 整数列表
- **字典说明**:
  - -1: 无该字段
  - 0: 未知
  - 1: 普通帽子
  - 2: 头盔
  - 3: 安全帽

## 4. emRainShedType
- **含义**: 雨棚（伞）类型
- **类型**: 整数
- **字典说明**:
  - -1: 无
  - 0: 不撑伞
  - 1: 人非手撑伞
  - 2: 未知
  - 3: 非机动车装载雨伞
  - 4: 非机动车装载雨棚

## 5. tpurl
- **含义**: 事件主图URL地址
- **类型**: 字符串

## 6. riderFaceUrls
- **含义**: 骑手人脸图片URL地址列表
- **类型**: 字符串数组
